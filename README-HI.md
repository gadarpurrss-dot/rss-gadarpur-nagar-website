# RSS Gadarpur Nagar — प्रारंभिक वेबसाइट/PWA नमूना

## इसमें क्या है
- हिंदी/अंग्रेजी भाषा बदलने का बटन
- मोबाइल-अनुकूल वेबसाइट लेआउट
- गतिविधियाँ, सेवा कार्य, गैलरी, संपर्क और पंजीकरण के नमूना सेक्शन
- PWA manifest और service worker का प्रारंभिक सेटअप

## स्थानीय रूप से देखना
`index.html` को ब्राउज़र में खोलकर डिज़ाइन देखा जा सकता है। PWA install/offline सुविधाएँ जाँचने के लिए HTTPS होस्टिंग या localhost आवश्यक है।

## GitHub Pages पर प्रकाशित करना
1. GitHub पर नया Public repository बनाएँ।
2. इस ZIP की सभी फाइलें repository की root में अपलोड करें।
3. Settings → Pages खोलें।
4. Deploy from a branch चुनें, Branch: `main`, Folder: `/ (root)` चुनकर Save करें।
5. प्रकाशित URL खुलने के बाद मोबाइल Chrome में Add to Home screen/Install विकल्प जाँचें।

## अभी अधूरे/डेमो हिस्से
- फॉर्म केवल डेमो है; कोई डेटा सेव या भेजा नहीं जाता।
- कार्यकर्ता लॉगिन/व्यवस्थापक पैनल अभी शामिल नहीं है। इसे वास्तविक authentication और role-based access के साथ backend जोड़कर बनाना होगा।
- गैलरी में placeholder हैं; केवल अनुमति प्राप्त तस्वीरें/वीडियो जोड़ें।
- संगठन का अधिकृत लोगो, परिचय, संपर्क और कार्यक्रम विवरण सत्यापन/अनुमति के बाद ही जोड़ें।

## सुरक्षा
कभी भी Supabase `service_role` key या कोई secret key सार्वजनिक HTML/JavaScript repository में न रखें। सार्वजनिक पेज पर निजी सदस्य-सूची, फोन नंबर या व्यक्तिगत जानकारी बिना सहमति न डालें।
